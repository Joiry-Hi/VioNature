**VioNature is a retro-styled high-speed arena FPS deeply inspired by Quake movement and classic id Software DNA.**

Survive waves of enemies across four distinct map geometries, wield 9 weapons with dual fire modes, battle three unique bosses, and master an arsenal of movement techniques — rocket jumps, spear dashes, blink teleports, and low-gravity orbital strafing.

---

### The FPS Laboratory

VioNature ships with a **built-in developer console** and **200+ tunable parameters**. Every weapon stat, enemy property, movement value, and boss behavior lives in a plain-text config file — no modding tools required. Press `~` to open the console and live-tune any parameter while playing. If you love tweaking games as much as playing them, this is your sandbox.

---

### Key Features

**9 Weapons × Dual Modes** — Laser rifle, flamethrower, rocket launcher, shotgun, gravity nailer, infinity gauntlet, Longinus spear, nano constructor, and mystic staff. Each weapon has a primary fire and an alternate mode, giving 20+ distinct combat tools. Right-click to toggle.

**Movement Is Your Defense** — There are no health bars. Every hit is lethal unless you have Essence (extra lives). Survive by chaining rocket jumps, shotgun recoil dashes, spear thrusts, blink teleports, flight rigs, and low-grav suits into aerial movement chains that rival classic arena shooters.

**Four Map Geometries** — Flat circular arenas, vertical square obstacle courses with multi-tier platforms, spherical asteroid surfaces with orbital physics, and hollow-world interiors where gravity pulls outward.

**Three Unique Bosses** — Geometry Lord fires homing barrages and enrages at low HP. Slime King jumps, slams, and splits into clones on death. The Star of Bethlehem is a celestial entity immune to AoE and homing attacks — only direct impacts can touch it.

**Full Developer Console** — Press `~` to open. Tab-completion for 200+ config keys. Live parameter tuning without restarting. Arrow-key navigation. Command history. This turns the game into a real-time experiment lab.

**Essence Life System** — Collect rainbow star-octahedron pickups for extra lives. Getting hit consumes one life instead of killing you, granting brief invincibility and a knockback shockwave. Displayed as hue-cycling hexagram stars on the HUD.

**Duel Mode** — 1v1 (or 1v10) against AI Duelists that use all 9 weapons, time-stop, blink, and shield. Two AI tiers: random barrage and strategic counter-picking.

**Drone Swarm Command** — Deploy combat drones that use boids flocking behavior. Hold Right-Click for a tactical overlay with X-ray enemy markers. Set rally points to coordinate your drone fleet.

**Magic Circle System** — Summon pentagram circles with floating octahedron frames. Feed them plasma bolts, fireballs, rockets, or shotgun pellets, and they'll auto-fire homing purple-tinted versions at enemies. Deactivate with the Longinus Spear.

### Quick Start for Tinkerers

1. Launch the game in Tutorial mode
2. Press `~` to open the console
3. Type any parameter name — Tab to auto-complete
4. Try `gravity = 10`, `walk_speed = 20`, or `curse_orb_dps = 10`
5. When you find your perfect settings, edit `config/gameplay.cfg` to make them permanent

### Controls

| Input | Action |
|-------|--------|
| WASD | Move |
| Mouse | Aim (click the game canvas once in the browser to lock pointer control) |
| Left Click | Fire |
| Right Click (tap) | Toggle weapon alt-mode |
| Scroll Wheel | Switch weapons / adjust range |
| Space | Jump / Fly up |
| Shift | Run |
| 1–8 | Select weapons |
| 0 | Mystic Staff |
| ~ | Developer Console |
| Z / X / C | Space Suit / Flight Rig / Skates |
| P | Hide HUD |
| R | Reset |

Browser note: the HTML5 build automatically scales the 16:9 game view to fit the itch.io embed. If mouse-look stops after switching tabs or pressing Esc, click the game canvas again to regain pointer lock.
