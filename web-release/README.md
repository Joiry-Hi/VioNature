# Web Release Package

This folder collects the files that are useful when publishing the HTML5/WebAssembly version of VioNature.

## Files

| File | Purpose |
|------|---------|
| `dist/` | Expanded browser build for local preview and butler upload |
| `packages/vionature_itch_html5.zip` | Primary manual itch.io upload package |
| `packages/vionature_web.zip` | Generic browser build archive |
| `build/` | Emscripten/CMake intermediates generated by the build script |
| `ITCHIO_DESCRIPTION.md` | Copy-ready itch.io project page description |
| `ITCHIO_DEVLOG_WEB_RELEASE.md` | Copy-ready itch.io devlog post for the Web release |

## Rebuild

From the repository root:

```bash
bash scripts/build-web.sh
```

The script rebuilds `web-release/dist/`, then refreshes both zip files under `web-release/packages/`.

## Local Preview

```bash
cd web-release/dist
python3 -m http.server 8080
```

Open:

```text
http://localhost:8080/
```

If you were already inside `web-release/dist/` while rebuilding, leave and re-enter the directory before starting the server. The build script deletes and recreates `web-release/dist/`.

## itch.io Upload

Upload:

```text
web-release/packages/vionature_itch_html5.zip
```

Required settings:

- Mark the file as playable in the browser.
- Do not zip the `web-release/dist/` folder as an outer directory.
- The archive root must directly contain `index.html`.

The browser build requests fullscreen and pointer lock after the player clicks the game canvas. This is required by browser security rules; automatic fullscreen without a user gesture is not allowed.
